ScamShield Backend

Tech Stack
- Node.js
- Express.js
- PostgreSQL
- Prisma
- JWT
- bcrypt

Features
- User Signup
- User Login
- JWT Authentication
- Protected User Profile
- Logout
- Input Validation

API Endpoints
POST /api/auth/signup
POST /api/auth/login
POST /api/auth/logout
GET  /api/auth/me

Setup
npm install
npm run dev
